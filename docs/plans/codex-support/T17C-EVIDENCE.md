T17C closes parent T17 after T17A's installed wheel/sdist fix and T17B's six-bundle/freshness gate. It does not perform T14's live cross-host rehearsal, T18's release-command fixes, or any publication.

The default offline CI matrix now covers Python **3.11 and 3.14** on **Windows and Ubuntu**. Python 3.14 was the latest stable bugfix branch selected for this gate ([Python developer guide](https://devguide.python.org/versions/)). Each job runs the full default suite (live `eval` tests excluded), builds all three Claude and all three Codex bundles, checks tracked Claude plugin freshness, and packages/checks the Codex local catalog. macOS is **unverified**; Python 3.12 has no current CI job. A local Windows Python 3.13 full-suite run supplies additional intermediate-version evidence but is not substituted for any matrix job. No live model or provider CLI is invoked by the default CI suite.

The fixed `plan-v1.md`, `cli-preview-v1.json` and `legacy-ledger-v0.json` fixtures exercise a real Git repository with spaces in its path. They pin the two-layer plan parser, JSON preview schema/gate and read-only behavior, explicit migration requirement for legacy state, schema-2 round trip, backup bytes, attempt count, and no invented integration SHA. Existing T07, T11 and T05 tests cover invalid plans, all JSON gate codes and real-Git recovery paths; T17A/T17B tests cover isolated installed wheel and bundle freshness. The T17A installed-wheel probe now also imports optional behavioral judging under `python -I -S` and proves it remains absent without optional packages.
