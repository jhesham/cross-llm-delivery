# T13A implementation contract — standalone Codex installation

Implement a Python standard-library CLI `generator/install_codex.py`. It accepts one action (`--preview`, `--install`, `--uninstall`), an explicit `--scope-root PATH`, and `--bundle PATH` for preview/install or `--name cross-llm-<provider>` for uninstall. The only target for a bundle is `<scope-root>/.agents/skills/<bundle.name>`. No command may infer or mutate the current user's real home or Claude folders. Print deterministic JSON with action, target, outcome and any collision/error; failure is nonzero. Preview must not write.

The input is a generated Codex bundle with a YAML-first `SKILL.md`, matching frontmatter `name`, and vendored `scripts/run_delivery.py` plus `scripts/cld/__init__.py`. Restrict names to the three supported provider skill names. Reject source or target symlinks that can escape the selected scope, and reject source/target overlap. Do not recursively delete any directory without verifying the resolved target is beneath the selected scope and owned by this installer.

Install copies the bundle's source files (not a symlink) into a staged sibling and then publishes it. Python bytecode caches are runtime artifacts and must not become owned source files or prevent safe update/uninstall after the vendored driver runs. Include an ownership manifest in the installed folder, containing a stable installer marker and per-file SHA-256 hashes. A clean owned installation may update from a newer bundle; a local modification, extra non-cache file, absent/invalid manifest, or same-name unowned installation must block update and uninstall. Uninstall removes only a verified owned, unmodified folder. Failed operations leave an existing target unchanged. Preserve unrelated skill folders and project instructions.

Document source build, repo-scope install and explicit user-scope alternative in `INSTALL.md`, with commands that work when paths contain spaces, preview first, and no actual user-global install in this task. Recheck official discovery rules and cite them. Make the committed `tests/test_t13a_install.py` pass. Edit only `generator/install_codex.py` and `INSTALL.md`; do not edit tests, plan/contract, generators, tracked plugins, or engine. Run focused tests only; do not commit, push, dispatch providers, or install into real home.
