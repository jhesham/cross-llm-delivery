# T16 adapter implementation contract

Implement `CodexExecutor` in `engine/cld_providers/codex/provider.py` using the T15 contract. This dogfood subtask edits **only that file** and must pass `tests/test_t16_codex_adapter.py`. The lead owns provider registration, generated resources/bundles, CLI/default-model policy, additional review tests, and live proof afterward. Do not register `PROVIDER` in this subtask or invoke a real Codex model.

Constructor: `CodexExecutor(*, model, effort=None, sandbox="workspace-write", runner=cld.process.run_process, git_runner=cld.process.run_process, timeout=None, cancel=None, artifact_dir=None)`. Require an explicit model. The injected `runner(argv, cwd, **kwargs)` supports bounded process kwargs and returns an object with `returncode`, `stdout`, `stderr`, `error`, and `metadata()` like `ProcessResult`. Probe `codex --version` and `codex exec --help` through that runner with finite probe deadlines; call `check_capabilities` and fail with an actionable `ExecutorResult` if the binary/flags are unavailable. The probe is read-only and must not invoke inference. Respect the ambient user auth/config; never read/copy credential files or put prompt/credentials in argv or process metadata.

`run(task, workdir, feedback=None)` must reject ambient `CLD_EXECUTOR_DEPTH` values other than absent/zero before any process. Build a bounded one-slice prompt with the task brief, exact allowed files, acceptance test and optional feedback. `build_invocation` adds the executor role and fresh-session guard. Pass its `argv`, `cwd`, UTF-8 `stdin` text and `env` to the shared `run_process` with `deadline_seconds(timeout, dispatch=True)`, cancellation and artifact directory. Do not use a shell, resume, `--last`, permission bypass, or write artifacts inside the candidate. Preserve process metadata and a bounded diagnostic log using `cld.process.feedback`. Parse stdout/stderr through `parse_exec_output`; no diff capture on process/JSONL failure. Successful completion alone permits a Git diff capture through `cld.executors._capture.capture_diff(git_runner, cwd)`; CLD's independent candidate verifier remains the allowed-files authority. Do not claim JSONL item/file events or final prose as acceptance.

Return `ExecutorResult(ok=True, diff, files_changed, usage_raw, process, raw_log)` only after valid completion and diff capture. Pass known input/output/cache-read fields as `token_usage` but omit the T15 parser's derived `total`: the shared accounting layer will derive it and mark `total_source=derived_input_output`. Never invent cost or cache-write; missing usage remains unknown. On probe, parser, process, or diff error, return `ok=False` with no candidate diff and an actionable process error; retain diagnostics outside the worktree. Use only the fake-process offline tests for this subtask. Do not commit, push, call other providers, run a full suite, or invoke CLD recursively.
